# Gift delivery idempotency example

A public reference for handling checkout retries, delivery jobs, provider timeouts, and duplicate callbacks in a fictional digital gift service.

**Read the [published documentation](https://gift-delivery-idempotency-example.readthedocs.io/en/latest/)** for the request contract and failure cases.

## What's here

- `docs/index.md` explains the three IDs used by the example.
- `docs/contract.md` defines request and response behavior.
- `docs/failure-cases.md` lists recovery rules and test cases.
- `.readthedocs.yaml` and `mkdocs.yml` build the public docs.

This is an independent engineering example. It contains no customer data or redeemable codes and does not claim to implement an issuer's real delivery policy.
